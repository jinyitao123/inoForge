# Forge 项目中心页面合同

状态：2026-10-01 建模驱动样板迁移进行中。本文维护项目中心当前要求、对照和验收；历史项目计划合同仍维护 WBS/计划业务细节，不与本页重复。

## 入口与权威能力

- 应用：项目；正式导航入口为 `page_project_center`。该入口的列表现已嵌入模型驱动 `ListView`，保留既有详情及受控立项动作。同应用的 `forge_project` 对象路由仅作原生视图与独立读回对照，不能代替正式入口验收。
- RISEMAP 对应：RM-094 `https://risemap.cn/project/list`；2026-09-29 已观察表格、甘特切换、状态、分组、搜索及有数据时间线，编辑、异常和权限行为尚未在参考侧办理。
- 权威对象：`forge_project`。类型、客户与项目负责人通过 ObjectStack 关系读取；生命周期、权限和正式状态由 Forge 对象、动作与原生权限控制。
- 表格与甘特共用同一项目记录。表格字段及列宽、搜索、排序、20 条分页和甘特的起止／进度绑定由 `ProjectViews` 元数据声明。

## 样板要求与当前观察

2026-10-01 当前批次：共享 `projectGanttConfig` 由正式页面和注册对象视图共同消费，默认周粒度并绑定同一日期／进度／提示字段。正式页用 `view=gantt` 保存视图选择，进入详情保留该参数。ObjectUI 公共层透传宿主导航回调后，源码预览与安装版均已从实际甘特打开 `PG正式样板项目` 的正式详情，再通过浏览器返回甘特；刷新同 URL 仍选甘特。常驻搜索、无匹配、清除与刷新路径在源码预览已操作，甘特活动过滤由其独立查询消费；公共层未接收父表格分页行。最新安装版在 1280×720 下页根溢出为零、周期标签为单行 17.5px，图表已随一行记录收紧。窄屏工具栏已改为换行，其余响应式、分组／排序、提示内容及不同身份仍待完成。项目详情任务区的状态筛选与任务工作区项目范围由[项目计划合同](forge-project-plan-page-contract.md#forge-页面行为)记录；本批交付区“新建交付包”已直达交付包表单并传入当前项目，表单仅在同项目有已通过调试记录时允许提交，仍由正式 Action 校验项目为执行中、调试记录通过和四类资料。局部渲染测试通过，浏览器与角色观察仍待完成。交付区“分享记录”“下载与查看记录”“使用模板”仍是无操作入口；现有项目/交付对象和 Action 中没有对应的分享历史、下载查看记录或交付模板能力，必须作为未完功能保留，不能将 PC-05 标为完成（切片见[交付验收合同](forge-delivery-acceptance-slice.md)）。证据仅对应这批旧技术材料的组件路径，新业务材料按标准测试资料另建，不追改旧观察为完整业务通过。
