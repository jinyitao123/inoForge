# Forge 业务工作页样式合同（工时管理基线）

## 实时证据

- RISEMAP：`https://risemap.cn/project/timesheet`，2026-09-15 使用内置浏览器实时读取 DOM 并截图。
- Forge：`http://localhost:4386/_console/apps/forge/page/page_project_timesheet_cost`。
- 本合同只固化可跨业务复用的页面骨架。各页面字段、状态、动作和阻断仍以对应 RISEMAP 实时页面为准。

## 已观察的统一骨架

1. 页面只保留一层业务标题；标题上方显示业务分组面包屑，说明文字紧随标题。
2. 页面主操作位于标题区右上角。导出类动作可组成相邻按钮组，当前办理动作使用蓝色主按钮，普通动作使用白底描边按钮。
3. 条件区单独使用白色卡片；筛选控件同高、横向排列，窄屏才换行。
4. 指标卡采用等宽栅格、短标签、大数值和补充说明；没有业务指标的列表页不强行增加指标卡。
5. 主内容使用白色卡片。页签位于卡片顶部，筛选位于页签下方，表头使用浅灰背景，行高紧凑。
6. 空态位于表格内容区中央；分页固定在内容卡底部，展示记录数、每页数量和当前页。
7. 按钮圆角、控件高度、边框、主色、间距和字体层级统一复用 `forgeWorkPageUiCss`，不在每个财务页另造一套视觉语言。

## 采购发票对照结论

- RISEMAP 对应页：`https://risemap.cn/purchase/invoices`。
- 修正前 Forge 存在 Console 标题与业务标题重复、窄宽度下筛选提前换行、工具栏动作层级不清晰、分页脱离标准区域的问题。
- 本轮将采购发票接入统一工作页骨架，保留采购发票自己的实时页签、字段、筛选和动作。
- `邮件收票` 在 RISEMAP 是显式业务动作；Forge 尚未配置企业邮箱，因此保留可点击入口并明确显示能力边界，不伪造收票结果。

## 后续应用规则

- 供应链后续页面和财务页面逐页实时对照时，先套用本合同，再用该页 RISEMAP 事实补充专属布局。
- 页面若缺少对应 RISEMAP 可办理数据，只标记为待复核，不以统一样式完成代替业务闭环。
