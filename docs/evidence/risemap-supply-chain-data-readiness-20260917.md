## 仍待产生数据的页面（按依赖顺序）

1. 询价 → 采购订单：`RFQ-2026-0001` 发布 → 收集报价 → 确认比价 → 转采购单。
2. 采购订单 → 到货通知 → 到货登记：RM-PLC-1215C 命中全检方案 `QP-202609-0001`，登记后应进入「待检验库存」而非免检入库。
3. 待检验库存 → 检验单：填合格/不合格结果，生成检验单；不合格项用于打通「不合格处理 / 处置执行中心」。
4. 采购入库 / 入库明细 / 库存流水：由检验单执行入库。
5. 采购发票：登记已入库单的进项发票。
6. 采购退换货 + 采购退换货出库：基于不合格来料发起。
7. 供应商价格本：新建价格本（可与 RFQ 报价结果关联）。
8. 生产入库 / 其他入库 / 期初入库（其他入库为空）：手工入库单。
9. 库存锁定 / 库存盘点 / 调拨与借出 / 报损单 / 库存预警：库存作业单据。
10. 出库管理 6 页：销售订单 → 发货单 → 出库单 → 出库明细。
