# Forge 统一银行流水与往来账分配切片

更新于 2026-09-10。实现位于隔离分支 `codex/otc-bank-flow-reconciliation`，验收端口 `4375`，数据库 `.objectstack/otc-bank-flow-reconciliation.sqlite`。该库承接阶段 19 已停服的付款撤销快照；SQLite 完整性检查为 `ok`。

## 证据边界

RISEMAP RM-133 的 DR-1005 至 DR-1008 证明资金流水页统计流水总额、已分配、待分配和待审核金额，区分待分配、部分分配、已分配和待审核，并提供收支方向、流水类型及时间筛选。证据说明银行流水先分配到业务订单，审核后计入回款或付款。现有账号没有可办理流水，未取得同材料成功分配、审核和撤回结果。

本切片把已有应收应付作为明确核销目标，先完成可追溯的手工流水登记、单笔拆分、审核、取消和反审核。公开更新记录提及的 Excel 导入、后台导入任务、自动识别往来单位、批量审核、导出和手续费处理均未据此推定实现。

## 已实现行为

- 在启用资金账户登记收入或支出，登记时仅更新一次账户余额；同账户银行参考号重复、交易早于期初日期、余额不足及收支方向与往来单位类型冲突会被阻断。
- 一笔收入可分配到同客户应收，一笔支出可分配到同供应商应付；每次分配形成待审核记录，并分别维护已审核、待审核和待分配金额。
- 审核收入分配后更新应收、销项发票、销售订单、合同和项目回款累计；审核支出分配后更新应付。待审核分配可以取消并释放金额。
- 已审核分配按审核时间逆序反审核，恢复对应业务账但不重复移动资金；全部分配取消或反审核后，可以冲销原流水并回退账户余额。
- 统一银行流水页展示四项金额、方向与状态筛选、流水明细和分配记录，并支持登记、分配、审核、取消、反审核和整笔冲销。

## 验证结果

定向 API 验收 5 组全部通过。验收账户以 `10000` 开始，登记收入 `1000` 和支出 `800` 后为 `10200`。收入先审核分配 `600`、再取消待审核 `200`；支出审核分配 `800`。两个方向反审核后，应收恢复 `121600`、应付恢复 `6800`，账户仍为 `10200`；再冲销两笔流水，账户恢复 `10000`。验收同时覆盖匿名访问、重复银行参考号、超额分配和重复状态阻断。

内置浏览器在真实统一银行流水页选择独立账户，登记收入 `800`，分配并审核 `300`。最终流水状态为部分分配，已审核 `300`、待审核 `0`、待分配 `500`，账户为 `5800`，应收余额同步从 `121600` 降至 `121300`。页面证据见 `docs/evidence/forge-bank-flow/bank-flow-kpis.jpg` 和 `docs/evidence/forge-bank-flow/bank-flow-ledger.jpg`。

服务完整停止后使用同一 SQLite 文件重启，API 流水仍为已冲销，浏览器流水和分配仍分别为部分分配、已审核，15 条操作记录完整回读；SQLite 完整性检查为 `ok`。元数据为 111 个对象、1786 个字段、27 个页面和 140 个动作；`typecheck`、`validate` 和 `build` 均通过。

## 未证明范围

- RISEMAP 同材料流水登记、分配、审核、取消和反审核尚未实际办理，Forge 行为待对照。
- 不含 Excel 或银行文件导入、后台任务、自动识别往来单位、批量审核、修改类型、导出、手续费拆分、账户间划转双边记账和银行余额对账。
- 当前统一入口不强制替代既有收款与付款动作；历史直接收付款记录也没有自动迁移为银行流水。
- 不含关账期间、总账凭证、银行回单附件、岗位权限、并发锁和数据库事务级原子回滚。
