# Forge 项目计划与执行页面契约

日期：2026-09-10。范围：产品化 P2。

## 用户任务

项目经理从计划列表找到项目计划，在同一页面查看阶段、里程碑和任务层级，切换只读甘特图核对日期，更新任务或里程碑进度，提交日报，并立即回读计划进度、阶段进度、实际日期和日报内容。

## RISEMAP 依据

- `docs/references/risemap-capture/deep/project/project-center/rm094/1008-rm094-gantt.png`：项目计划详情中的列表、甘特图与进度视图入口及甘特布局。
- `docs/references/risemap-capture/deep/project/task-management/rm096/1024-rm096-gantt.png`：任务管理甘特视图的名称列与时间轴结构。
- 已有 `project-plan.integration.mjs` 和 `project-plan-execution.integration.mjs` 固化了同材料确认的阶段、里程碑、任务、前置关系、进度状态、实际日期、阶段简单平均回算和日报字段。

## 页面行为

- 默认进入计划列表，可按计划、编号或项目搜索并按状态筛选；创建计划前必须明确选择进行中或已暂停的项目。
- 详情页在一个计划上下文提供“计划表”“甘特图”“进度与日报”三页签。计划表按阶段展开工作项，显示前置关系、计划与实际日期、进度和状态。
- 甘特图仅根据已保存的计划日期绘制，里程碑使用菱形标记，延期项单独着色。时间轴不提供拖动。
- 新增工作项、更新进度和提交日报使用对话框；失败时保留输入，成功后重新读取计划及关联记录。
- 原始工作项和日报对象不再作为用户导航入口，仍保留对象 API 和控制台调试能力。

## 已知边界

- 第一版不提供拖动排程、计划基线、修订流转和自动关键路径计算。
- 前端按钮可见性只反映记录状态，不代表岗位权限控制。
- 附件上传仍由原始字段能力承载，本页面本批次不提供附件控件。
- RISEMAP 已确认单一前置关系；Forge 现有服务端支持多个前置关系，该能力继续标记为待同材料复核。

## 验收条件

使用独立端口和独立 SQLite，从计划列表打开同一条计划，新增一个任务，更新进度，提交日报，切换甘特图并回读全部结果；随后完整停服并从同一数据库重启，再次从页面打开该计划。桌面尺寸检查 1440×900 与 1280×800，页面整体无横向溢出，宽表和甘特仅在内容容器内滚动。
