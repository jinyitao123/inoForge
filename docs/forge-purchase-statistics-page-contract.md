# Forge 采购统计页面合同

状态：2026-09-29 建模驱动样板进行中。旧[采购统计取证](evidence/reports-system-placeholders-20260921/page-purchase-statistics.md)保留受验版本与历史结论；本页维护当前目标和待验证项。

## 入口、口径与对照

- 正式入口：报表应用的 `page_purchase_statistics`。RISEMAP 对应 RM-150 `https://risemap.cn/reports/purchase`，当前观察涵盖维度导航、订单／供应商／采购员搜索、组织与日期范围、采购额、订单数、入库、待付款、趋势、漏斗和排行；其成功写入业务链未在本轮复核。
- 权威数据：采购订单、明细、到货／入库、应付、供应商和人员各归其业务对象。指标口径由 Forge 合同决定，不把不同对象的记录拼成页面上的静态数字。
- 原生建模样板：`forge_purchase_order_metrics` 以采购订单为基表，声明状态、下单月份、供应商维度和订单数／订单金额度量；`forge_purchase_order_summary` 用该数据集呈现状态分组与金额。该样板只覆盖采购订单部分，不承诺已覆盖入库、应付、质检或供应商排行。
