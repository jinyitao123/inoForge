## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已取证 | 已有截图、页面状态、DOM 或操作记录，能说明某个入口、字段、动作或结果真实存在 |
| 可进入实现 | 核心字段、关系、正常路径和至少一次保存核对结果明确，具备同输入复测案例 |

| 完整验收 | 模块内正常、异常、权限、配置、导入导出、打印、下游影响和恢复要求均已证明 |
